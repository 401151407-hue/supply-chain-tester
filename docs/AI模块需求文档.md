# AI 助手 & 模型配置 需求文档

> 版本: v0.2.83 | 日期: 2026-07-26

---

## 一、模型配置模块

### 1.1 入口
- 左侧菜单栏「模型配置」按钮（原「AI 算力」）

### 1.2 功能需求

| 编号 | 功能 | 描述 |
|------|------|------|
| MC-01 | 启用/禁用 AI | 开关控制全局 AI 功能启用状态 |
| MC-02 | 提供商快捷选择 | 4 列网格按钮：内部算力、DeepSeek、通义千问、月之暗面。点击自动填入 API 地址和模型名 |
| MC-03 | API Key 输入 | 密码框输入，每个提供商独立保存，切换不互串 |
| MC-04 | API 地址 | 选择提供商自动填入，支持手动修改 |
| MC-05 | 测试连接 | 保存当前配置后用选定模型发送 "hi" 测试连通性 |
| MC-06 | 保存配置 | 持久化到本地，同时更新后端 AI 服务 |

### 1.3 提供商预设

| 提供商 | API 地址 | 可选模型 |
|--------|---------|---------|
| 内部算力 | `http://10.100.22.203:30080/llmsec/wxsllm/v1` | llm-pro / llm-plus / llm-flash |
| DeepSeek | `https://api.deepseek.com/v1` | deepseek-v4-pro / deepseek-v4-flash |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | qwen-max / qwen-plus / qwen-turbo |
| 月之暗面 | `https://api.moonshot.cn/v1` | moonshot-v1 |

### 1.4 Key 管理规则
- 内部算力：内置默认 Key，用户不可见
- 外部提供商：需用户自行申请 Key，独立存储在 `localStorage`（key: `ai-key-{模型名}`）
- 切换提供商时：有已保存 Key → 自动填入；无 → 显示空白

## 二、AI 助手模块

### 2.1 入口
- 左侧菜单栏「AI 助手」按钮

### 2.2 功能需求

| 编号 | 功能 | 描述 |
|------|------|------|
| AI-01 | 多轮对话 | 支持上下文连续对话，自动维护历史 |
| AI-02 | 对话管理 | 左侧面板展示所有对话，支持新建、切换、删除 |
| AI-03 | 模型切换 | 顶部下拉选择模型，每条对话独立绑定模型 |
| AI-04 | 中文模型名 | 下拉框显示「模型名」+「中文标注」（如 `deepseek-v4-pro` `DeepSeek · V4 Pro`） |
| AI-05 | 自动聚焦 | 发送消息后输入框自动获取焦点 |
| AI-06 | 流式输出 | 最终回复逐字显示（当前为非流式，待优化） |
| AI-07 | 思考指示器 | 三个跳动圆点 + 工具状态文字（与回复气泡视觉区分） |
| AI-08 | 自动命名 | 首次发言自动取前 20 字作为对话标题 |

### 2.3 工具调用（Tool Calling）

| 编号 | 工具 | 描述 | 权限 |
|------|------|------|------|
| TC-01 | readFile | 读取任意文件内容 | 只读，直接执行 |
| TC-02 | writeFile | 写入/创建文件 | 需用户确认 |
| TC-03 | listDir | 列出目录内容 | 只读，直接执行 |
| TC-04 | browserOpen | 打开网页 | 需用户确认 |
| TC-05 | browserRead | 读取页面文本 | 只读，直接执行 |
| TC-06 | browserClick | 点击页面元素 | 需用户确认 |
| TC-07 | browserType | 输入文字 | 需用户确认 |
| TC-08 | browserScreenshot | 截取页面 | 只读，直接执行 |

#### 工具调用规则
- 格式：`<tool name="工具名">{"参数": "值"}</tool>`
- 修改类操作弹出确认框，用户批准后执行
- 最大 8 轮工具调用，防止死循环
- 工具结果超过 600 字符自动截断
- 对话历史压缩：系统提示 + 最近 8 条消息

### 2.4 系统提示词

AI 助手注入以下上下文：
- **工作区路径**：当前项目根目录
- **工具文档**：所有可用工具的说明和示例
- **行为指令**：主动探索、先读后写、中文回复

### 2.5 Agent 角色（已保留但界面简化）

| Agent | 描述 |
|-------|------|
| 通用助手 | 全能型，回答各类问题 |
| 测试工程师 | 设计测试用例、生成步骤 |
| 代码专家 | 编写和优化 Python 脚本 |
| 日志分析师 | 分析错误堆栈和日志 |

## 三、技术架构

### 3.1 数据流
```
用户输入 → preload (IPC) → main process → AIService → OpenAI 兼容 API
                                                         ↓
用户界面 ← preload (IPC) ← main process ← 流式/非流式响应
```

### 3.2 存储
| 数据 | 存储位置 |
|------|---------|
| AI 配置（启用/Key/地址） | 主进程 config + renderer store |
| 提供商独立 Key | `localStorage: ai-key-{模型名}` |
| 对话线程 | `localStorage: ai_threads` |
| 活跃线程 ID | `localStorage: ai_active_thread_id` |
| 自定义模型列表 | `localStorage: ai-custom-models` |

### 3.3 Token 优化
- 历史压缩：系统提示 + 最近 8 条
- 工具结果截断：600 字符
- 不重复推送带 tool 标签的 AI 回复

---

## 四、已知限制

1. **流式输出**：当前为非流式，逐字显示待后续版本优化
2. **API 频率限制**：DeepSeek 免费 API 有速率限制
3. **工具调用格式**：XML 标签格式，部分模型（如 DeepSeek Flash）遵循度较低，建议用 Pro 版本
4. **Key 管理**：仅本地存储，不加密
