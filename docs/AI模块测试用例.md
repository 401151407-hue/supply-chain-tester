## 一、模型配置模块

### MC-01: 启用/禁用 AI

| 用例ID | 场景 | 前置条件 | 步骤 | 预期结果 |
|--------|------|---------|------|---------|
| MC-01-01 | 默认启用 | 首次打开面板 | 查看启用开关 | 开关为开启状态 |
| MC-01-02 | 关闭 AI | AI 已启用 | 点击开关关闭 → 保存 → 进入 AI 助手发消息 | 提示"AI 服务不可用" |
| MC-01-03 | 重新启用 | AI 已关闭 | 点击开关开启 → 保存 → 测试连接 | 连接成功 |

### MC-02: 提供商快捷选择

| 用例ID | 场景 | 前置条件 | 步骤 | 预期结果 |
|--------|------|---------|------|---------|
| MC-02-01 | 选择内部算力 | 面板打开 | 点击「内部算力」按钮 | API 地址填入内部 URL，按钮高亮 |
| MC-02-02 | 选择 DeepSeek | 面板打开 | 点击「DeepSeek」按钮 | API 地址填入 `https://api.deepseek.com/v1` |
| MC-02-03 | 选择通义千问 | 面板打开 | 点击「通义千问」按钮 | API 地址填入阿里云 DashScope 地址 |
| MC-02-04 | 选择月之暗面 | 面板打开 | 点击「月之暗面」按钮 | API 地址填入 Moonshot 地址 |
| MC-02-05 | 切换提供商 | 已选 DeepSeek，已输入 Key | 点击「通义千问」 | API 地址切换，Key 清空（外部未配置） |
| MC-02-06 | 切回已配置提供商 | 已配置并保存 DeepSeek Key | 切换到通义千问 → 再切回 DeepSeek | DeepSeek Key 自动回填 |

### MC-03: API Key 管理

| 用例ID | 场景 | 前置条件 | 步骤 | 预期结果 |
|--------|------|---------|------|---------|
| MC-03-01 | 内部算力 Key 不可见 | 选择内部算力 | 查看 Key 输入框 | 显示内置 Key（密码框） |
| MC-03-02 | 外部提供商 Key 为空 | 首次选择 DeepSeek | 查看 Key 输入框 | 显示空白 |
| MC-03-03 | 输入并保存 Key | 选择 DeepSeek | 输入 Key → 保存 | 保存成功提示 |
| MC-03-04 | Key 独立存储 | 分别配置 DeepSeek 和千问 Key | 切换两个提供商 | Key 独立显示，不互串 |
| MC-03-05 | 重新打开面板 | 已保存 DeepSeek Key | 关闭面板 → 重新打开 → 选择 DeepSeek | Key 自动回填 |

### MC-04: API 地址

| 用例ID | 场景 | 前置条件 | 步骤 | 预期结果 |
|--------|------|---------|------|---------|
| MC-04-01 | 自动填入 | 点击提供商 | 查看 API 地址 | 自动填入对应地址 |
| MC-04-02 | 手动修改 | API 地址已填入 | 手动改为其他地址 → 保存 → 测试 | 使用手动输入的地址 |
| MC-04-03 | 地址直接可见 | 面板打开 | 查看 API 地址输入框 | 始终可见，不折叠 |

### MC-05: 测试连接

| 用例ID | 场景 | 前置条件 | 步骤 | 预期结果 |
|--------|------|---------|------|---------|
| MC-05-01 | 内部算力测试 | 已选内部算力 | 点击「测试连接」 | 连接成功 ✓ |
| MC-05-02 | DeepSeek 正确测试 | 已选 DeepSeek + 正确 Key | 点击「测试连接」 | 连接成功，显示部分回复内容 |
| MC-05-03 | 错误 Key 测试 | 已选 DeepSeek + 错误 Key | 点击「测试连接」 | 显示 HTTP 401/403 错误 |

| MC-05-05 | 未保存直接测试 | 修改配置后未点保存 | 点击「测试连接」 | 自动保存后测试（正常） |

### MC-06: 保存配置

|--------|------|---------|------|---------|

## 二、AI 助手模块

### AI-01: 多轮对话

| 用例ID | 场景 | 前置条件 | 步骤 | 预期结果 |
|--------|------|---------|------|---------|
| AI-01-01 | 首次对话 | 新建对话 | 输入"你好" → 发送 | AI 正常回复 |
| AI-01-02 | 上下文记忆 | 刚问过"1+1=?" | 接着问"刚才的答案乘以2" | AI 回答 4 |
| AI-01-03 | 多轮不丢上下文 | 连续 5 轮对话 | 每轮都引用上一轮内容 | AI 正确理解上下文 |
| AI-01-04 | 空消息拦截 | 输入为空 | 点击发送 | 不发送（按钮禁用） |

### AI-02: 对话管理

| 用例ID | 场景 | 前置条件 | 步骤 | 预期结果 |
|--------|------|---------|------|---------|
| AI-02-01 | 对话列表展示 | 有多条对话 | 查看左侧面板 | 所有对话以列表形式展示 |
| AI-02-02 | 新建对话 | 在任意对话中 | 点击 + 按钮 | 创建"新对话"，自动切换 |
| AI-02-03 | 切换对话 | 有多条对话 | 点击另一条对话 | 切换到该对话，显示其历史 |
| AI-02-04 | 删除对话 | 有 >1 条对话 | 悬停 → 点击 X | 对话被删除，切换到剩余对话 |
| AI-02-05 | 删除最后一条 | 只有 2 条对话 | 删除当前对话 | 切换到另一条，界面正常 |
| AI-02-06 | 当前对话高亮 | 有多条对话 | 查看列表 | 当前对话有左侧色条 + 高亮 |
| AI-02-07 | 清空对话 | 对话中有多条消息 | 点击清空按钮 | 消息清空，显示欢迎语 |

| 用例ID | 场景 | 前置条件 | 步骤 | 预期结果 |
